# Step 5.07: Home Defense Kit Zip (archiver)

## Install archiver

```bash
cd apps/api && pnpm add archiver && pnpm add -D @types/archiver
```

## apps/api/src/routes/family.ts — add kit download endpoint

```typescript
import archiver from 'archiver';
import { createHomeDefenseKit } from '../services/canary';

// GET /api/family/home-defense-kit — generates canary tokens and returns zip
familyRouter.get('/home-defense-kit', requireAuth, async (req, res) => {
  const userId = req.user!.id;

  // Generate 5 canary tokens
  const tokens = await createHomeDefenseKit(userId);

  // Build a zip containing text files that explain each token + the download URL
  res.set('Content-Type', 'application/zip');
  res.set('Content-Disposition', 'attachment; filename="DefendDaily_HomeDefenseKit.zip"');

  const archive = archiver('zip', { zlib: { level: 9 } });
  archive.pipe(res);

  const readme = `# DefendDaily Home Defense Kit
  
These 5 files are "canary tokens" — digital traps for intruders.

INSTRUCTIONS:
1. Place each file in your Documents folder (or Desktop)
2. Do NOT open them yourself
3. If DefendDaily alerts you that one was opened, your device may be compromised

Files included:
- documents_backup.docx  (Word document token)
- important_info.pdf     (PDF token)
- passwords_backup.xlsx  (Excel token — DO NOT USE as real password storage)
- family_photo.jpg       (Image token)
- bank_portal.url        (Web shortcut token)

If triggered, immediately:
1. Disconnect from the internet
2. Run antivirus scan
3. Contact IT support

Generated by DefendDaily SentryLife on ${new Date().toLocaleDateString()}
`;

  archive.append(readme, { name: 'README.txt' });

  for (const [i, token] of tokens.entries()) {
    const fileTypes = ['documents_backup.docx', 'important_info.pdf', 'passwords_backup.xlsx', 'family_photo.jpg', 'bank_portal.url'];
    const content = `This file is a DefendDaily canary token.\nToken URL: ${token.token_url}\nDo not open this file.`;
    archive.append(content, { name: fileTypes[i] ?? `canary_${i}.txt` });
  }

  await archive.finalize();
});
```

Wire into index.ts: `receiver.app.use('/api/family', familyRouter);`
